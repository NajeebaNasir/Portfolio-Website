## ⚡ Overview & Tech Stack
A responsive, high-performance static web application built to showcase my technical background in **GenAI Engineering**, **Agentic AI Systems (LangGraph, MCP)**, and **Cloud Architecture**.

- **Structure**: HTML5 Semantic Markup & Modular Architecture
- **Styling**: Modern Obsidian Dark Theme, Glassmorphism 2.0, CSS Grid & Custom Properties
- **Logic**: Vanilla JavaScript (ES6+), Dynamic Skill Matrix Filtering & Background Particle Canvas
- **Deployment**: Static Site Hosting via GitHub Pages
